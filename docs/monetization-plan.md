## 3. O11y Watch Pro — $6/month or $60/year
Offer (near-zero extra time; everything comes from the weekly `check.mjs` run Kurt already does):
- **Same-day alerts**: when the check finds a real change, send a one-paragraph broadcast to the `pro` segment the same day instead of waiting for the weekly issue (~5 min per change).
- **Snapshot history**: the `snapshots/` + `reports/` archive (all saved versions and diffs).
- **Exports**: `vendors.csv`, `changes.csv`, full JSON with history — generated by the build script (TODO once first subscriber pays: add `npm run export` → zip on an unlisted URL).
Price rationale: impulse-level for an engineer (below a $10 expense threshold), comparable to small dev data newsletters' $5–10/mo; annual = 2 months free. 20 subscribers ≈ $1.4k/yr.

### How to deliver Pro at $0 — recommended setup
**Kit Commerce on the Kit Free plan** (confirmed: "Digital products and subscriptions" are included on Free; fee 3.5% + $0.30/transaction, no monthly fee; Stripe is the processor, Kit creates a new Stripe account during setup; weekly payouts). Sources: https://help.kit.com/en/articles/16627071-the-kit-free-plan, https://help.kit.com/en/articles/4199324-sell-digital-products-with-kit-overview-and-faqs
1. Kit → Products → create "O11y Watch Pro", subscription, $6/mo; a second product (or price) $60/yr.
2. Fulfillment: "Go to URL" → an unlisted page (e.g. `/pro-members-<random>.html`, noindex) with the export downloads. Buyers are automatically recorded in Kit, so you can segment them for broadcasts.
3. Paste the product checkout URL into `STRIPE_PRO_LINK` and rebuild.
4. Limits on Free plan: no automations/sequences, so alerts are manual broadcasts to the buyer segment (fine at this scale); "Built with Kit" badge stays. Kit collects VAT only, not US sales tax.

Alternative: plain **Stripe Payment Link** (2.9% + $0.30, cheaper) + manually tagging buyers in Kit (Stripe emails you each sale). Cheaper per sale but adds manual work and an extra dashboard; switch only if volume grows. For sponsors, a Stripe Payment Link (or Kit product) for each package works the same way → `STRIPE_SPONSOR_LINK`.

Unlisted URL ≠ real access control; acceptable for $6 data exports. Rotate the URL if it leaks.
