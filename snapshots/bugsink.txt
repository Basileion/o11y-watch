Self-host
To evaluate Bugsink by self-hosting it, spin up a throw-away instance using Docker:
Copy
docker pull bugsink/bugsink:latest
docker run \
-e SECRET_KEY=SVRAzMZNzduIsn18HTT8rVg6rKgQ4aJRJ43VsegeLDjGFl1MNT \
-e CREATE_SUPERUSER=admin@example.org:admin \
-e PORT=8000 \
-p 8000:8000 \
bugsink/bugsink docker pull bugsink/bugsink:latest
bugsink/bugsink
Visit http://localhost:8000/ , where you'll see a login screen. The default username and password
are admin .
Now, you can set up your first project and start tracking errors.
